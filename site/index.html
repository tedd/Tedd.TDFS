Filesystem semantics

From write to recovery.

{ }

Publish a revision

By default, a stream buffers writes privately. Flush or close it to publish a durable revision. Readers see a complete version of the file.

⇄

Commit files together

Group updates to multiple paths in one volume. A strictly serializable transaction publishes all of its changes at a single commit boundary.

◷

Read a recovery point

Open a read-only snapshot while the live volume keeps changing. An independent backup host can receive complete snapshots incrementally.

Live directory exports for SMB gateways

Bind a share to a directory identity. The volume leader enforces sharing across clients and tracks the opened file through rename and delete-on-close. Shared writers publish each write through the leader. The Windows profile adds case-insensitive names and preserves their spelling.

Exports are opt-in per volume. Standard opens incur no additional cross-node lock request.
